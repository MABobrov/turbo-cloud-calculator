# Эксплуатация

## 1. Запуск

| Способ | Команда |
| --- | --- |
| Локально | `turbo-calc serve --port 8000` |
| Docker | `docker run --rm -p 8000:8000 turbo-cloud-calculator` |
| Kubernetes | Deployment с 2+ репликами; readiness probe — `GET /health` |

## 2. Проверка работоспособности

`GET /health` возвращает статус, версию, дату прайс-листа и число позиций:

```json
{"status": "ok", "version": "1.0.0", "pricelist_captured_at": "2026-10-29", "pricelist_items": 82}
```

## 3. Журнал

Сервис пишет одну строку на запрос: `request_id`, метод, путь, код ответа, время в миллисекундах. Передайте заголовок `X-Request-ID`, чтобы связать запрос с журналом вызывающей системы.

## 4. Обновление прайс-листа

Предупреждение: изменение цен меняет контрольные суммы в тестах. Обновите ожидаемые значения в `tests/test_calculator.py` в том же коммите.

1. Снимите цены с сайта turbocloud.ru/prices.
2. Измените `turbo_calc/data/pricelist.json`: значения `price` и поле `captured_at`.
3. Запустите `pytest`.
4. Увеличьте версию в `pyproject.toml` и `turbo_calc/__init__.py`.
5. Соберите образ и выполните развёртывание.

## 5. Откат

Разверните предыдущий тег Docker-образа. Сервис не имеет состояния; откат не требует миграций.

## 6. Типовые ошибки

| Симптом | Причина | Действие |
| --- | --- | --- |
| `422` с полем `extra_forbidden` | Опечатка в имени поля | Проверьте имя поля по `/docs` |
| `422` «Для кластера h200 укажите h200_profile» | Неполная конфигурация GPU | Укажите профиль и число карт |
| Сервис не стартует, ошибка «Дублирующийся SKU» | Повреждён прайс-лист | Исправьте JSON, запустите `pytest` |
