# Требования к калькулятору стоимости

Документ фиксирует требования к программе Turbo Cloud Calculator. Требования согласованы с заказчиком — коммерческим блоком ООО «Турбо».

## 1. Цель

Менеджер по продажам и клиент должны получать смету за секунды, без ручного переноса цен из прайс-листа в Excel. Смета должна совпадать с расчётом биллинга с точностью до копейки.

## 2. Пользователи

| Роль | Сценарий |
| --- | --- |
| Менеджер по продажам | Готовит коммерческое предложение по заявке клиента |
| Клиент | Оценивает бюджет на инфраструктуру до обращения в продажи |
| Разработчик личного кабинета | Вызывает REST API из формы «Калькулятор» |
| Аналитик | Выгружает сметы в CSV для сравнения вариантов |

## 3. Функциональные требования

| ID | Требование | Приоритет |
| --- | --- | --- |
| FR-1 | Программа принимает конфигурацию ресурсов в формате JSON | Обязательно |
| FR-2 | Программа считает стоимость виртуальных машин: vCPU, RAM, диски, ОС, IP | Обязательно |
| FR-3 | Программа считает стоимость GPU-ВМ для кластеров L40S, L4, H200 | Обязательно |
| FR-4 | Программа считает стоимость кластеров Kubernetes | Обязательно |
| FR-5 | Программа считает стоимость управляемых СУБД и брокеров | Обязательно |
| FR-6 | Программа считает стоимость объектного хранилища S3 по трём тарифам | Обязательно |
| FR-7 | Программа считает стоимость резервного копирования | Обязательно |
| FR-8 | Программа считает стоимость Inference Platform с почасовой оплатой | Обязательно |
| FR-9 | Программа считает стоимость сетевых сервисов: IP и каналы | Обязательно |
| FR-10 | Программа применяет скидку в процентах к сумме без НДС | Обязательно |
| FR-11 | Программа считает НДС по заданной ставке; значение по умолчанию — 22 % | Обязательно |
| FR-12 | Программа считает срок от 1 до 36 месяцев и среднемесячный платёж | Обязательно |
| FR-13 | Программа выводит смету в форматах text, JSON, CSV | Обязательно |
| FR-14 | Программа предоставляет REST API с OpenAPI-документацией | Обязательно |
| FR-15 | Программа возвращает список ошибок конфигурации с указанием поля | Обязательно |
| FR-16 | Программа принимает внешний прайс-лист | Желательно |

## 4. Нефункциональные требования

| ID | Требование | Критерий приёмки |
| --- | --- | --- |
| NFR-1 | Точность | Расчёт в `Decimal`; округление каждой строки до копейки `ROUND_HALF_UP` |
| NFR-2 | Производительность | Расчёт одной конфигурации — не более 50 мс; API — не менее 200 запросов в секунду на одном ядре |
| NFR-3 | Надёжность | Некорректный ввод не приводит к падению процесса; ответ `422` с описанием |
| NFR-4 | Безопасность | Неизвестные поля запрещены; размеры списков и значений ограничены; контейнер работает без прав root |
| NFR-5 | Наблюдаемость | Каждый запрос имеет `X-Request-ID`; время обработки пишется в журнал |
| NFR-6 | Переносимость | Python 3.11–3.13; Linux, macOS, Windows; Docker-образ |
| NFR-7 | Сопровождаемость | Покрытие тестами не менее 90 %; `mypy --strict`; `ruff` |
| NFR-8 | Обновляемость цен | Прайс-лист — отдельный JSON-файл с датой снятия цен |

## 5. Регуляторные требования

| Норма | Как учтена |
| --- | --- |
| НК РФ, гл. 21 (ставка НДС 22 % с 01.01.2026) | Ставка задаётся в конфигурации; значение по умолчанию — 22 % |
| 152-ФЗ «О персональных данных» | Программа не хранит персональные данные. Поле `customer` — необязательное, не сохраняется на сервере |
| 149-ФЗ, реестр отечественного ПО | Программа не зависит от иностранных облачных сервисов; работает в закрытом контуре |
| Правила округления (Положение ЦБ РФ о бухгалтерском учёте) | Денежные значения — два знака после запятой, `ROUND_HALF_UP` |

## 6. Ограничения

- Прайс-лист соответствует публичным ценам на дату `captured_at`.
- Программа не считает стоимость SaaS-приложений и профессиональных сервисов.
- Программа не создаёт коммерческое предложение как документ. Эту функцию выполняет CRM.

## 7. Формат конфигурации

| Поле | Тип | Ограничение | По умолчанию |
| --- | --- | --- | --- |
| `customer` | строка | до 200 символов | — |
| `months` | целое | 1…36 | 1 |
| `discount_percent` | десятичное | 0…50 | 0 |
| `vat_percent` | десятичное | 0…30 | 22 |
| `vms[]` | VirtualMachine | до 200 элементов | [] |
| `gpu_vms[]` | GpuVirtualMachine | до 50 элементов | [] |
| `kubernetes[]` | KubernetesCluster | до 20 элементов | [] |
| `databases[]` | ManagedDatabase | до 50 элементов | [] |
| `object_storage[]` | ObjectStorage | до 20 элементов | [] |
| `backup` | Backup | — | — |
| `inference[]` | InferenceWorkload | до 20 элементов | [] |
| `network` | Network | — | без IP и канала |

Полная схема полей — в `turbo_calc/models.py` и в `/openapi.json`.
