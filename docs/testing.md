# Тестирование

## 1. Стратегия

| Уровень | Инструмент | Что проверяет |
| --- | --- | --- |
| Статический анализ | `ruff`, `mypy --strict` | Стиль, ошибки, типы |
| Модульные тесты | `pytest` | Прайс-лист, модели, расчёт |
| Интеграционные тесты | `pytest` + `httpx.TestClient` | REST API: коды ответов, заголовки, схема |
| Сквозные тесты | `pytest` + CLI | Расчёт из файла, форматы вывода, коды возврата |
| Контроль покрытия | `pytest-cov` | Порог 90 %; фактически 98 % |

## 2. Состав тестов

| Файл | Тестов | Содержание |
| --- | --- | --- |
| `tests/test_pricelist.py` | 15 | Загрузка, уникальность SKU, цена за единицу, ошибки |
| `tests/test_calculator.py` | 32 | Контрольные суммы по каждому сегменту; скидка; НДС; округление |
| `tests/test_api.py` | 9 | `/` (веб-интерфейс), `/health`, прайс-лист, расчёт, `422`, `404`, `X-Request-ID` |
| `tests/test_cli.py` | 7 | Форматы text/JSON/CSV, запись в файл, ошибки ввода |
| `tests/load/locustfile.py` | — | Нагрузочный сценарий (запускается отдельно) |

Контрольные суммы в `test_calculator.py` посчитаны вручную по прайс-листу. Это защищает от регрессий при изменении формул.

## 3. Запуск

```bash
pip install -e ".[dev]"
ruff check .
mypy turbo_calc
pytest
```

## 4. Проверка веб-интерфейса

Сценарий на Playwright: открыть `/`, загрузить пример «веб-приложение», дождаться итога, сравнить с результатом `turbo-calc estimate examples/web-app.json`; загрузить пример «ИИ-платформа»; очистить форму и убедиться, что пустая конфигурация даёт сообщение об ошибке. Итоги в браузере и в CLI совпали: 1 061 124,33 ₽ и 6 822 744,64 ₽.

## 5. Нагрузочное тестирование

Команда для проверки NFR-2:

```bash
turbo-calc serve &
pip install locust
locust -f tests/load/locustfile.py --headless -u 50 -r 10 -t 60s --host http://127.0.0.1:8000
```

Целевые показатели: p95 ответа `/v1/estimate` — не более 50 мс; ошибок — 0.

Результат 29.10.2026 (50 пользователей, 30 с, один процесс uvicorn): 7 948 запросов, 0 ошибок, медиана 7 мс, p95 21 мс, 234 запроса в секунду на `/v1/estimate`.

## 6. Тестирование безопасности

- `pip-audit` проверяет зависимости на известные уязвимости.
- Модели `extra="forbid"` и ограничения диапазонов проверяются тестами на отклонение некорректных данных.
- Контейнер запускается без прав root; проверка — `docker run --rm turbo-cloud-calculator id`.
